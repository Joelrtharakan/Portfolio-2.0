# **App Name**: Immersive Portfolio 3D

## Core Features:

- 3D Animated Hero Section: Interactive 3D background with dynamic text and a call to action button featuring a neon glow effect.
- Interactive 3D Avatar: 3D avatar/model with subtle animations providing a visual representation in the 'About Me' section.
- Skills Sphere/Solar System: An interactive 3D display of skills in a rotating sphere or solar system configuration.
- AI Support Ticket Summarizer: Summarize the contents of a support ticket to make it easier for the portfolio user to know how best to route a piece of work. The summarizer is a tool, not necessarily applied to every ticket, based on the bot's judgment.
- Project Showcase with Flipping Cards: Projects displayed as 3D flipping cards with animated previews and a modal with full details.
- 3D Vertical Timeline: A 3D vertical scrolling timeline to showcase the portfolio owner's experience with glowing icons.
- Interactive Contact Form with 3D Globe: Contact form with a glassy design and a 3D globe highlighting Dubai/India.

## Style Guidelines:

- Primary color: Futuristic electric blue (#7DF9FF), reminiscent of neon lights and digital displays.
- Background color: Dark, desaturated blue-gray (#293132), to enhance the contrast and give a professional look.
- Accent color: Deep purple (#5800FF) for interactive elements and highlights, providing a creative flair.
- Body and headline font: 'Space Grotesk', sans-serif for headlines, and 'Inter', sans-serif, for body text, combining a techy feel with readability.
- Use glowing, minimalist icons that complement the 3D elements.
- Employ a split layout design with asymmetrical balance to enhance visual interest and engagement.
- Implement smooth page transitions, scroll-triggered 3D animations, and magnetic button effects using Framer Motion.
